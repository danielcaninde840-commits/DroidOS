# Teste e criação do pendrive

1. Construa a ISO em Debian 13 AMD64.
2. Teste a ISO em máquina virtual antes de gravar.
3. Use Rufus ou balenaEtcher para gravar a ISO híbrida no pendrive de 32 GB.
4. No Rufus, se solicitado, use modo de gravação DD para preservar a estrutura
   híbrida da imagem.
5. Selecione UEFI no menu de boot do notebook.
6. Escolha o modo Live e teste todos os dispositivos.

**Atenção:** gravar a ISO apaga o conteúdo do pendrive. A instalação no HD/SSD
é uma etapa separada e pode apagar seus dados; faça backup antes.
